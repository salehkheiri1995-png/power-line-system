# Power Line Data Management System

سیستم مدیریت و تحلیل تعمیرات خطوط برق (بک‌اند FastAPI + فرانت‌اند React/Vite).

## پیش‌نیازها

- Python 3.10+
- Node.js 18+
- Git

## راه‌اندازی بک‌اند

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # در ویندوز
pip install -r requirements.txt
```

متغیرهای محیطی (اختیاری – برای production توصیه می‌شود):

- `POWER_LINE_SECRET_KEY`  کلید JWT
- `POWER_LINE_DATABASE_URL`  آدرس دیتابیس (پیش‌فرض: `sqlite:///./power_line.db`)

اجرای سرور:

```bash
cd backend
venv\Scripts\activate
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

## راه‌اندازی فرانت‌اند

```bash
cd frontend
npm install
npm run dev
```

در حالت توسعه، Vite درخواست‌های `/api` را به `http://localhost:8000` پروکسی می‌کند.

## ورود داده از فایل اکسل

از منوی «📥 ورود از اکسل» می‌توانید فایل `xlsx` را انتخاب کنید یا داخل کادر رها کنید.

- سطر عنوان ستون‌ها به‌صورت خودکار در ۱۵ سطر اول فایل پیدا می‌شود.
- شیت‌های اطلاعاتی (مثل «اطلاعات فیلتر») نادیده گرفته می‌شوند.
- تاریخ‌های میلادی و سریال تاریخ اکسل خودکار به شمسی تبدیل می‌شوند.
- دو حالت دارد: **افزودن به داده‌های موجود** یا **جایگزینی کامل داده‌ها**.
- به‌صورت پیش‌فرض بعد از ورود داده، خطوط، دکل‌ها و سوابق تعمیر هم از روی رکوردها ساخته می‌شوند
  (این گزینه با تیک «ساخت خطوط، دکل‌ها و سوابق تعمیر» قابل غیرفعال‌کردن است).
- در صفحه «مدیریت خطوط» دکمه «🔄 بارگذاری» همین کار را دستی انجام می‌دهد و تکرارشدنی است
  (سوابق تکراری دوباره ثبت نمی‌شوند).
- ستون‌های قابل شناسایی: نوع برنامه، کد، نام خط، سطح ولتاژ، شرح انجام کار، شماره دکل،
  موقعیت، تاریخ pm، تاریخ انجام، تعداد اکیپ، تعداد نفرات، نام سرپرست اکیپ، مقدار، واحد،
  شماره دکل ۲ و عنوان کار.

همین کار از طریق API هم ممکن است:

```bash
curl -X POST "http://localhost:8000/api/upload-excel?mode=append" \
  -H "Authorization: Bearer <TOKEN>" \
  -F "file=@data.xlsx"
```

`mode` می‌تواند `append` (پیش‌فرض) یا `replace` باشد.

## اجرای سریع با اسکریپت

در ریشه‌ی پروژه:

```bash
start.bat
```

این اسکریپت بک‌اند (روی پورت 8000) و فرانت‌اند (روی پورت 5173) را با هم اجرا می‌کند.
